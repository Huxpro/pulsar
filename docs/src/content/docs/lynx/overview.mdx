Lynx Pulsar gives your [Lynx](https://lynxjs.org) app haptic feedback through a native module that talks to Core Haptics on iOS. It ships **151 hand-crafted presets** (anvil, heartbeat, balloonPop, …), a **pattern composer** for custom haptic sequences, and a **realtime composer** for gesture-driven feedback.

## Install

```bash
npm install lynx-pulsar
```

Peer dependency: `@lynx-js/react >= 0.118`. You also need a Lynx host that registers `PulsarLynxModule` so JS calls reach Core Haptics — the [Lynx Pulsar host](https://github.com/Huxpro/pulsar/tree/lynx-port/lynx/lynx-pulsar) included in this fork does it end-to-end; integrating into your own iOS host follows the same pattern as any Lynx native module. See [How it works](/pulsar/lynx/architecture/) for the wiring details.

## Use it in your app

```tsx
import { Presets, usePatternComposer, useRealtimeComposer } from 'lynx-pulsar';

// Play a preset
<view bindtap={() => Presets.dogBark()}>
  <text>Bark</text>
</view>

// System haptics
Presets.System.impactMedium();
Presets.System.notificationSuccess();

// Custom pattern
const composer = usePatternComposer({
  discretePattern: [
    { time: 0,   amplitude: 1.0, frequency: 0.8 },
    { time: 100, amplitude: 0.5, frequency: 0.5 },
  ],
  continuousPattern: {
    amplitude: [{ time: 200, value: 0.3 }, { time: 400, value: 0 }],
    frequency: [{ time: 200, value: 0.2 }, { time: 400, value: 0.2 }],
  },
});
composer.play();
```

The full API is on the [SDK reference](/pulsar/sdk/lynx/) page.

## Try the demo

The fastest way to feel what it does is to install the showcase app on your iPhone. Clone the repo and install JS deps:

```bash
git clone https://github.com/Huxpro/pulsar.git
cd pulsar
( cd lynx/lynx-pulsar && npm install )
( cd lynx/lynx-pulsar-app && npm install )
```

Then build the iOS host and ship the bundle — full walkthrough (simulator path, physical-device path, troubleshooting) on the [run the demo](/pulsar/lynx/build-prompt/) page. First-time setup is ~30 minutes (mostly Lynx C++ pods); subsequent rebuilds run in a few minutes.
