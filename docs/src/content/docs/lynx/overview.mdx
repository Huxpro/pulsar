Lynx Pulsar gives your [Lynx](https://lynxjs.org) app haptic feedback through a native module that talks to Core Haptics on iOS. It ships **151 hand-crafted presets** (anvil, heartbeat, balloonPop, …), a **pattern composer** for custom haptic sequences, and a **realtime composer** for gesture-driven feedback.

## Try it

The fastest way to feel what it does is to install the demo on your iPhone:

```bash
git clone https://github.com/Huxpro/pulsar.git
cd pulsar
( cd lynx/lynx-pulsar && npm install )
( cd lynx/lynx-pulsar-app && npm install )

cd ~/github/lynx-pulsar-explorer/explorer/darwin/ios/lynx_explorer
xcodebuild -workspace LynxExplorer.xcworkspace -scheme LynxExplorer \
  -configuration Release \
  -destination "generic/platform=iOS" \
  -allowProvisioningUpdates \
  -derivedDataPath build clean build

# Package + install (UDID from `idevice_id -l`)
cd build/Build/Products/Release-iphoneos
mkdir Payload && cp -R LynxExplorer.app Payload/
zip -rq /tmp/lynx-pulsar.ipa Payload/
ideviceinstaller -u <UDID> install /tmp/lynx-pulsar.ipa
```

Full step-by-step (including simulator path, host project setup, troubleshooting) on the [run the demo](/pulsar/lynx/build-prompt/) page.

## Use it in your app

```tsx
import { Presets, usePatternComposer, useRealtimeComposer } from 'lynx-pulsar';

// Play a preset
<view bindtap={() => Presets.dogBark()}>
  <text>Bark</text>
</view>

// System haptics
Presets.System.impactMedium();
Presets.System.notificationSuccess();

// Custom pattern
const composer = usePatternComposer();
composer.discrete({ time: 0,   intensity: 1.0, sharpness: 0.8 });
composer.continuous({ start: 0.2, end: 0.4, intensity: 0.3, sharpness: 0.2 });
composer.play();
```

The full API is on the [SDK reference](/pulsar/sdk/lynx/) page.

## How it ships

`lynx-pulsar` is a Lynx native module wrapping Pulsar's Swift SDK. On iOS, your Lynx app's host needs to register `PulsarLynxModule` so JS calls cross into Core Haptics. The provided [Lynx Pulsar host](https://github.com/Huxpro/pulsar/tree/lynx-port/lynx/lynx-pulsar) does this for you; integrating into an existing iOS host follows the same pattern as any Lynx native module.
