A complete walkthrough — clone the repo, build the bundle, install the host, launch the app — for both the iOS Simulator and a physical iPhone.

**Time budget.** ~30 min the first time on a fresh machine (almost all of it is the initial `pod install` for Lynx's C++ pods like PrimJS — see the [host setup notes](https://github.com/Huxpro/pulsar/blob/lynx-port/lynx/AGENTS.md)). Once the host is set up, subsequent rebuilds take a few minutes — and rspeedy hot-reload during JS iteration is sub-second (see [Iterating during development](#iterating-during-development) below).

## Prerequisites

- macOS with Xcode 15+
- Node 18+, npm 9+
- The Lynx Pulsar host project at `~/github/lynx-pulsar-explorer/` with `pod install` already completed. First-time host setup (one-time, ~30 min for the initial `pod install` because of PrimJS) is documented at [`lynx/AGENTS.md → LynxExplorer Integration (iOS)`](https://github.com/Huxpro/pulsar/blob/lynx-port/lynx/AGENTS.md).
- For the physical-device path: a paired iPhone and `ideviceinstaller` (`brew install ideviceinstaller`).

## Install JS dependencies

```bash
git clone https://github.com/Huxpro/pulsar.git
cd pulsar
( cd lynx/lynx-pulsar && npm install --no-audit --no-fund )
( cd lynx/lynx-pulsar-app && npm install --no-audit --no-fund )
```

## Build on iOS Simulator

```bash
# Boot any iPhone simulator if none is booted
xcrun simctl boot 'iPhone 17 Pro' 2>/dev/null || true
open -a Simulator

DEVICE_ID=$(xcrun simctl list devices booted -j \
  | python3 -c 'import sys,json; print(json.load(sys.stdin)["devices"].values().__iter__().__next__()[0]["udid"])')

cd ~/github/lynx-pulsar-explorer/explorer/darwin/ios/lynx_explorer
xcodebuild -workspace LynxExplorer.xcworkspace -scheme LynxExplorer \
  -configuration Release \
  -destination "platform=iOS Simulator,id=$DEVICE_ID" \
  -derivedDataPath build clean build

xcrun simctl install booted build/Build/Products/Release-iphonesimulator/LynxExplorer.app
xcrun simctl launch booted com.huxpro.lynx.pulsar
```

The app boots straight into the Presets tab. The iOS Simulator does not have a haptic engine, but you can verify the UI loads and the bundle URL resolution works.

## Build on a physical iPhone

```bash
DEVICE_UDID=$(idevice_id -l | head -1)

cd ~/github/lynx-pulsar-explorer/explorer/darwin/ios/lynx_explorer
xcodebuild -workspace LynxExplorer.xcworkspace -scheme LynxExplorer \
  -configuration Release \
  -destination "generic/platform=iOS" \
  -allowProvisioningUpdates \
  -derivedDataPath build clean build

cd build/Build/Products/Release-iphoneos
rm -rf Payload && mkdir Payload && cp -R LynxExplorer.app Payload/
zip -rq /tmp/lynx-pulsar.ipa Payload/
ideviceinstaller -u "$DEVICE_UDID" install /tmp/lynx-pulsar.ipa
```

First time on a device, you must trust the developer cert:
**Settings → General → VPN & Device Management → Trust "Apple Development: ..."**.

Then tap **Lynx Pulsar** on your home screen. The Presets tab loads with all 151 cards; tap any of them to feel it.

## Iterating during development

The build steps above produce a release-mode `.lynx` bundle and ship it inside the app. For a faster iteration loop, run the dev server and use the host's Bundle URL field instead:

```bash
# Terminal A
cd lynx/lynx-pulsar-app && npm run dev
# rspeedy prints e.g. http://192.168.x.y:3003/main.lynx.bundle
```

```bash
# Terminal B — install the debug-configured host first
xcodebuild ... -configuration Debug build
xcrun simctl install booted .../Debug-iphonesimulator/LynxExplorer.app

# Seed the URL into the simulator's pasteboard, launch the host
echo "http://127.0.0.1:3003/main.lynx.bundle?fullscreen=true" \
  | xcrun simctl pbcopy booted
xcrun simctl launch booted com.huxpro.lynx.pulsar
```

Tap the URL field in the host's home card → long-press → Paste → tap **Go**. Hot reload works for all subsequent edits.

## Common pitfalls

| Symptom | Cause / Fix |
|---|---|
| `xcrun simctl install` errors with "no devices booted" | Boot a simulator first via Simulator.app or `xcrun simctl boot`. |
| Build fails at `Bundle Pulsar Lynx code` Run Script | The Run Script copies `lynx-pulsar-app/dist/main.lynx.bundle` into the app's `Resource/` folder ([how it works](/pulsar/lynx/architecture/#the-bundle-pipeline)). Either keep your `Huxpro/pulsar` checkout at `~/github/pulsar`, or set `LYNX_PULSAR_APP_DIR` in an Xcode user xcconfig. |
| Device install fails with "ApplicationVerificationFailed" | Indicates a code signature mismatch. Re-archive Release cleanly: `xcodebuild ... clean build`. |
| `npm: command not found` during the build phase | Xcode strips `PATH`. The script prepends `/opt/homebrew/bin:/usr/local/bin`; edit if your `npm` lives elsewhere. |

If you want to see how the Run Script and bundle pipeline work, the [How it works](/pulsar/lynx/architecture/) page explains the moving parts.
